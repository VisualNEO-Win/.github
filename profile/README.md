## How VisualNEO Win Sits

VisualNEO Win does not replace the files you already keep for that app. It sits beside them as a named visual designer for a VisualNEO Win desktop app you own.

If two people share a PC, each keeps a VisualNEO Win builder desk of their own. Extra screens wait for their own title instead of crowding the live project.

A first visit should be one short page, then the same VisualNEO Win app project the next day. That is enough to see if the layout holds on an app you keep.

## Traffic Light

| Signal | On the VisualNEO Win builder desk | What you do |
|--------|-----------------------------------|-------------|

| Amber | Screens from two apps mixed | Split the set before a large change |
| Red | No title, scattered screens everywhere | Stop and name the app project first |
| Clear | Handoff written, page list short | Close VisualNEO Win and leave the desk |

## Open Order

1. Open the last VisualNEO Win session on an app you keep, not a new empty project.
2. Read the visual designer, the page list, and the last handoff.
3. Finish one visible page inside VisualNEO Win app project.
4. Write what changed on the desktop app you own, then close with fewer loose screens than you found.
5. If the builder desk feels crowded, drop anything that belongs to a different VisualNEO Win job.

## After a Week

A week in VisualNEO Win is not more live screens. It is the same visual designer, a shorter page list, and a note that still makes sense on Monday.

Take finished pages off the live set so the next visit starts on the VisualNEO Win desktop app that is still open.

Other programs stay where they are. VisualNEO Win only keeps the path back: project name, pages, designer, handoff.
